# 📧 Professional Email Signature Generator

## ✨ Project Overview

This is a modern, responsive web application built using **Django** and **Bootstrap 5** to quickly generate professional, cross-client compatible **HTML email signatures**.

The tool provides a clean, live preview so users can see exactly what the final signature will look like before copying.

## 🚀 Key Features

* **Responsive UI:** Works perfectly on mobile, tablet, and desktop.
* **Live Preview:** Instant visualization of the generated signature.
* **Custom Styling:** Utilizes the clean and professional 'Poppins' font.
* **Easy Setup:** Simple to deploy on any standard Django environment.

## 🛠️ Tech Stack

* **Framework:** Django
* **Frontend:** HTML, CSS, Bootstrap 5

## 💻 Setup Instructions

Follow these commands to run the project locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/ankitab78/Email-signature-generator.git](https://github.com/ankitab78/Email-signature-generator.git)
    cd Email-signature-generator
    ```

2.  **Activate Virtual Environment** (Highly Recommended):
    ```bash
    # For Windows
    .\venv\Scripts\activate
    ```
    *(Note: You need to create the venv first: `python -m venv venv`)*

3.  **Run the application:**
    ```bash
    python manage.py runserver
    ```
    Access the app at `http://127.0.0.1:8000/`.
